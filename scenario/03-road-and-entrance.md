# 03. 第2章：遺跡への道

**想定時間**：約1.5時間　**戦闘**：1回（研究員ゾンビ）

---

## シーン3-1：出発準備

- 買い物フェイズを設ける（実プレイでは各自ポーション・オヴ・ヒーリング×2を購入）
- 食料などは**ボブが手配**する（**バッグ・オヴ・ホールディング**所持）
- 遺跡までは **2週間** の道のり

---

## シーン3-2：旅路の会話 ― ボブの人物像

**【確定】** ボブへの質問に対する回答（台詞そのまま使用可）：

> 「私の仕事は**研究職**です。遺跡の研究をしています」
> 「**代々そういう家系**でしてね。マジックアイテムやらをいじるのが好きなのです」
> 「それは危険なのは皆さんと同じです。私も冒険者と同じように**求めるものがある**からしょうがないですね」
> 「彼の遺跡についてはある程度知っていますよ。**潜入していました**からね」

### 遺跡（ジャッジの研究所）の見取り図を提示

```
館内 地下1F
 ├ 資料庫
 ├ 発掘品保管庫
 ├ 研究室
 ├ 実験室
 └ 遺跡入口
```

> **GMへ**：「代々そういう家系」はボブの正体（セレス家）の伏線である。
> さらっと流し、後で回収すること。

---

## シーン3-3：エアリュオン、二度目の出現 【言語の壁を突破するシーン】

**【確定】** 夕食時、**ボブの姿が突然消え**、彼女が現れる。

> 「来てくれたんだね…優しい人たち」
> 「どうかこの人たちが怪我をしませんように…無事にここまでこれますように…」

- **こちらの声は届かない**が、**姿と動きは見えている**
- 筆談を試みると「**すごいこの小さい子何か書いている**」と反応する
  → つまり文字は見えているが**読めない**

### 言語パズル

| 試行 | 反応 |
| --- | --- |
| 共通語の文字 | 「小さい子はなんて書いているんだろう…昔は覚えてたんだけどな…この文字…」 |
| エルフ語 | ？を浮かべる |
| **竜語** | 「！」「**読める！読めるよ！**」 |

> **GMへ**：ここは**必ず突破させる**こと。詰まったら以下でヒントを出す。
> - 彼女がPCの幻影や物体をじっと見る（＝視覚は通じている）
> - 「ドラゴン」に関する話題に反応が良い
> - コンプリヘンド・ランゲージ、トング、《言語習得》系特技でも代替可
> - どうしても手段がない場合、ボブが「試しに竜語で書いてみては？」と助言する **【補完】**

### 突破後に得られる情報

質問に応じて、以下を小出しにする。

| 質問 | 回答 |
| --- | --- |
| （ボブの姿を見せて）知り合いか | 「この人は知り合いじゃないよ。**昔仲良かったヒューマンに似ている**だけ」 |
| どれくらい昔か | 「昔は昔。**大昔。季節が何千回と移り変わる前**。私がまだ小さかった頃の話」 |
| 食事について | 「君たちが作るものはどれも素敵なんだ。音楽も絵も食事も。どれもキラキラしてお腹がたくさん膨れそうで」<br>「**一度でいいから食べてみたかったな**」 |
| なぜ食べられない | 「食べたことがないだけ、私は遠くから見てただけ。**私が近づくとみんなが傷つく**」 |
| 何が起きているのか | 「**あの子も傷つけてしまった。**私は多くの人を傷つけてきた。そして今も私のせいで…」<br>「この地は今にもひっくり返りそうになっている」 |

締めの台詞：

> 「だから**お願い、私をどうか殺してください**。これ以上誰も傷つけないために」
> 「どうか、あなた達も無事でいてね」
> 「もう時間か…ごめんね。またね。」

### 聖邪感知への対応

**【確定】** パラディンの聖邪感知、ディテクト・イーヴル・アンド・グッド等：
> **反応なし。彼女は邪悪ではない。**

これはPCの倫理的な迷いを解く重要な情報である。

### ボブの再登場

彼女が消えると同時にボブが現れる。

> 「困りますよ。皆さん、あの幽霊が**私の顔を覚えたら**どうするんですか」
> 「私が幽霊が怖いんですよ…」
>
> （「大昔からの知り合いでしょ？」と問われたら）
> 「**私の知り合いではないですよ**」　※嘘ではない。知り合いだったのは先祖である
>
> （「彼女は邪悪ではなかった」と伝えられたら）
> 「彼女が邪悪じゃないか…それは良かった」「**本当に**」

> **GMへ**：この「本当に」に感情を込めること。
> 後から思い返したときに、ボブの真意が漏れていた瞬間だと分かるように。

## シーン3-4：遺跡入口 ― 研究員ゾンビ戦

**【確定】** 2週間の旅を終え、遺跡入口に到着。

> ボブ「ここが遺跡の入口だ」
> 「このさきにジャッジの研究所があり、その先に遺跡がある」
> 「しかし、ここにはおそらく**奴ら**が潜んでいるだろう」
> 「ああ、私が研究所から逃げ出す原因になった**命無きもの**」
>
> （その時だった。地面から湧きだつように手が伸びてくる）
>
> 「**アンデッドだ**」

### ボブの離脱

> 「さて、ここは任せたよ。みんな。僕は先にジャッジの様子を見てくる」
> （そう言い残し、ボブは姿を消した）

> **GMへ**：ボブはこの戦闘に参加しない。
> 以後、第3章のクライマックスまで姿を見せない。
> PCに「薄情な男だ」と思わせておくのが正しい。

### 敵：錬金術ゾンビ（研究員ゾンビ）×3〜4体

**【確定】** データ：

| 項目 | 内容 |
| --- | --- |
| 攻撃 | **腐敗の拳**：近接武器攻撃 +3、間合い5ft、目標1体。ヒット：1d6+1［殴打］+3［毒］ |
| 特徴：**錬金術ゾンビ** | ［光輝］ダメージ、またはクリティカル・ヒットで倒した場合、錬金残留反応は**作動しない** |
| 特徴：**錬金残留反応** | HPが0になった時、10フィート以内の全クリーチャーが **DC12【敏捷力】セーヴ**。失敗で下表のランダム効果（1d6） |

| d6 | 効果（ランダム爆発） |
| --- | --- |
| 1 | 酸の爆発（2d6［酸］ダメージ） |
| 2 | 火の閃光（2d6［火］ダメージ） |
| 3 | 催涙蒸気（1ターン盲目状態） |
| 4 | 麻痺毒（1ターン麻痺状態） |
| 5 | 粘着液（1ターン拘束状態） |
| 6 | 回復液（アンデッド種は2d4HP回復する） |

**【補完】** 推奨ステータス：AC8 / HP 22 / 移動20ft（『Zombie』ベース）。
「怖気づく」「有頂天な」「酔っ払いの」「自己中心的な」など、
**生前の性格を冠した個体名**を付けると味が出る（実プレイでの表記）。

### 戦闘のポイント

- 「倒すと爆発する」という構造上、**近接アタッカーが不利**になる
- 第3章の資料庫で「みんなばくはつする」の手記を読んでいれば納得感が出るが、
  本シナリオでは**戦闘が先**である。つまり **後から答え合わせが来る** 構成
- ［光輝］ダメージ持ち（パラディン、クレリック、ドルイド星座形態など）が輝く場面

### 戦闘後

遺体の埋葬・処理をロールプレイさせる（モールド・アース等）。
館内に入ると案内図があり、地下1Fの構成が確認できる。
