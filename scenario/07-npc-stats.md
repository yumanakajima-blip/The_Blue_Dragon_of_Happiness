### エアリュオン

| 項目 | 内容 |
| --- | --- |
| 幻影の姿 | 綺麗な青い目をした、ボロボロの少女 |
| 真の姿 | **アダルト・ブルードラゴン**（片翼欠損、耳が潰れている、全身に古傷） |
| 制約 | **聴覚なし／共通語の文字が読めない／竜語のみ通じる** |
| 状態 | 雷の檻に拘束。ヒーリングポーションの点滴で「血を絞るためだけに」生かされている |
| 戦闘 | **戦闘には参加しない**（衰弱して動けない） |
| 名の意味 | 「幸せを運ぶ風」 |

**演技指針**：
- 敵意はゼロ。ずっと謝っている
- 自分が悪いと信じ込んでいるが、実際には**何もしていない**
- 人の作るもの（音楽、絵、食事）に強い憧れがある
- 優しい言葉をかけられると、少し微笑む

**【補完】** どうしても戦闘データが必要な場合は
『Adult Blue Dragon』から HPを1/4、ブレスと飛行を削除、
状態異常「無力状態」相当を付与した状態で運用する。

### エアリュオン（蘇生後）

リインカーネイトによりヒューマン等の人型種族として復活。
明るく食いしん坊で、街のすべてに感動している。酒場で働き始める。

## 敵データ

### ペンタドロン（第1章）

**【確定】** 特徴：

| 能力 | 内容 |
| --- | --- |
| **複数回攻撃** | 5回の "腕" 攻撃を行う |
| **麻痺ガス**（再チャージ5〜6） | 30フィート円錐の範囲にガスを噴出。範囲内のクリーチャーは **DC11【耐久力】セーヴ**、失敗で**1分間麻痺状態**。麻痺したクリーチャーは自分の各ターンの終了時に再セーヴ可、成功で効果終了 |

**【補完】** 推奨ステータス：AC15 / HP 40 / 速度40ft（『Pentadrone』準拠）。

**演技指針**：
- 秩序と支配を語るが、根は小物で愛嬌がある
- 名前を略されると激怒する（「私をその名で呼ぶな～！！！」）
- 不利になると土下座して命乞いする（が、内心は諦めていない）
- **筋（道理）は通す**。これが第5章の反転につながる

代表的な台詞：
> 「この世界は私というルールによって、支配されるのだ！」
> 「マジックミサイルは悪い文明だ」「やめてくれ」「ください」
> 「私はこの世界から争いをなくす！私にしかできない！私が神になるのだ！」

### モドロン（モノドロン／デュオドロン／トリドロン／クアドロン）

**【確定】** 特徴：

| 敵 | 複数回攻撃 |
| --- | --- |
| デュオドロン | 2回の "拳" 攻撃または2回のジャヴェリン攻撃 |
| トリドロン | 3回の "拳" 攻撃または3回のジャヴェリン攻撃 |
| クアドロン | **【補完】** 4回相当（原ログでは戦闘前にクイズで機能停止） |
| モノドロン | **【補完】** 1回（同上） |

**【補完】** 推奨ステータス：MM準拠（Monodrone AC15/HP5、Duodrone AC15/HP11、
Tridrone AC15/HP16、Quadrone AC16/HP22）。

**演技指針**：
- ペンタドロンの「急ごしらえ」であり、統率が取れていない
- のんきで人懐こく、PCにすぐ絆される
- 「はーい」「うん」「あい」「わかた」など片言
- クイズに正解されると素直に褒め、情報をくれて去る
- 去り際に **PCの背景を刺す一言** を残すこと

### ペンタドロン（第4章以降／ウォーフォージド体）

| 項目 | 内容 |
| --- | --- |
| 外見 | ウォーフォージドらしき生命体。**エフィのマジック・ミサイルの傷**が残っている |
| 経緯 | 敗北後、地獄で悪魔と契約して肉体を得た |
| 所持品 | 封印用の壺型マジックアイテム、ネザースクロール、ウイングド・ブーツ、フェザーフォールの巻物 |
| 戦闘 | **原則として戦闘しない**（第4章では立ち去り、第5章では交渉相手になる） |

**【補完】** PCが第5章で戦闘を選んだ場合は、
CR7〜9相当（AC17 / HP 110 / 悪魔由来の火炎攻撃）で運用する。
ただしこの戦闘に物語上の意味はないので、勧めない。

### 錬金術ゾンビ（研究員ゾンビ／第2章）

**【確定】** 特徴：

| 能力 | 内容 |
| --- | --- |

| **錬金術ゾンビ** | ［光輝］ダメージ、またはクリティカル・ヒットの場合、錬金残留反応は作動しない |
| **錬金残留反応** | HPが0になった時、10ft以内の全クリーチャーが **DC12【敏捷力】セーヴ**。失敗で下記1d6のランダム効果 |

| d6 | 効果 |
| --- | --- |

### ジャッジ・アイアンハート（第3章ボス）

**【確定】** 特徴：

| 能力 | 内容 |
| --- | --- |
| **複数回攻撃** | 1回のクレーンアーム攻撃と1回のスクリューアタック攻撃。いずれかを**力場弾**に置き換え可 |
| **クレーンアーム** | 命中+8、ダメージ 1d6+5［斬撃］、間合い10ft（2マス） |
| **投擲**（BA） | クレーンアームで捕まえたクリーチャーを9m先（6マス）に投げる。着地先に他のクリーチャーがいれば両者2d6［殴打］。投擲先のクリーチャーが **DC15【筋力】〈運動〉** 成功で両者ダメージなし |
| **自己崩壊の呪い** | 重傷状態のまま1ラウンド経過で発動。**次のラウンド終了時に爆発して即破壊**。同エリアの全クリーチャーは **DC16【敏捷力】セーヴ**。失敗で**残りHPに等しい**［力場］ダメージ、成功で半分 |

**【補完】** 推奨ステータス：AC16 / HP80 / 速度30ft。

**演技指針**：
- 会話が通じない。PCを「研究員ども」と呼ぶ
- 「掘る」ことしか考えていない
- 撃破時にだけ、一瞬正気が戻る：「私は真実が…未知が知りたかった…」

### 天空遺跡のドラゴンたち（第4章）

**敵ではない。** 襲ってこない。PCを憐れんでいる。
正体は、かつてこの遺跡を訪れて竜と化した者たち（ドワーフ、エルフ、ヒューマン等）。

クリスタルが破壊されると元の姿に戻り、そのまま息絶えて灰になる。
