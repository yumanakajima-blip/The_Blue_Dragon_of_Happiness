# 02. 登場人物

## プレイヤーキャラクター（PC）

### ヴィルフリート（愛称：ヴィル）

| 項目 | 内容 |
| --- | --- |
| 種族 | スカージ・アアシマール |
| クラス | パラディン |
| 特徴 | 常に仮面を着用。アアシマールの証である「輝く目」を隠し、内なる光を制御・抑制するため |
| 装備・能力 | ロングソード（後に +1 ロングソード）、聖邪感知、癒しの手、神聖なる一撃、聖なる光の解放（自己を焼く光） |
| 入館料に納めた品 | 自身の日記『守護天使ラキュエルとの愉快適悦な日々』 |

騎士然とした丁寧語で話す前衛役。パーティーの盾として最前線に立ち続けた。
第5話ではドラゴン化した際に知性が下がり、「おれ はらへった」とフィルネを食べ物として
見つめるという名場面（迷惑）を残している。

### フィルネ

| 項目 | 内容 |
| --- | --- |
| 所属 | 天文台の星読み（ドルイド） |
| クラス | ドルイド／サブクラス「星々の円環」 |
| 特徴 | 好きな分野になると止まらない早口。暗視を持たない。動物会話が使える |
| 主な呪文 | エンタングル、ムーンビーム、ガイディング・ボルト、フェアリー・ファイアー、ディテクト・マジック、プロデュース・フレイム、フロストバイト、メンディング、ガイダンス |
| 星座形態 | 弓使い座（ボーナスアクションで光の矢を放つ） |
| 入館料に納めた品 | 自著『何故こぐま座は星2つでこぐまなのか？』（2年かけて承認を得た未公開本） |

「知識はあまねく万人のためのものです！」が信条。星読みとして地震の凶兆に敏感。
第5話では唯一ドラゴン化を免れ、竜と化した仲間たちを率いてクリスタルを破壊する立役者となった。

### エフィ

| 項目 | 内容 |
| --- | --- |
| 種族 | エルフ（自称500歳・自称「老人」） |
| クラス | ウィザード系（力術中心） |
| 主な呪文 | マジック・ミサイル（愛用）、シャター、マインド・スリヴァー、メイジ・アーマー、シェイプ・ウォーター |
| 背景 | 借金持ち。弟がいる（モノドロンに安否をほのめかされる）。ゼンタリムと繋がりがある様子 |

飄々とした軽口担当。ペンタドロンを「ペンくん」と呼んで因縁を作った張本人。
戦闘では後方からマジック・ミサイルを撃ち続け、ペンタドロンに一生モノの傷を残した。

### オニキス

| 項目 | 内容 |
| --- | --- |
| 種族 | 猫 |
| 肩書 | 大図書館キャンドルキープの**館長**（名物猫） |
| クラス | ローグ（急所攻撃、不動の照準）＋呪文使い |
| 主な呪文 | メイジ・ハンド（不可視）、メンディング、メイジ・アーマー、トウル・ザ・デッド、サイレント・イメージ、モールド・アース |
| 会話手段 | 首の文字盤／石板に魔法で文字を浮かべる。共通語のほか竜語も解する |

実質的な狂言回し。かつての飼い主である「おじいさん」から青き竜の逸話を聞いており、
おじいさんが大切にしていた本と絵が事件の発端になる。
ボブの指輪をメイジ・ハンドで盗む、扉を開ける、翻訳する、猫パンチでゴーレムに
クリティカルを叩き込むなど八面六臂の活躍を見せた。

## 主要NPC

### 司書（キャンドルキープの案内人）

老齢の司書。「わしは正直者で売っているんじゃ」と言いつつ辛辣。
入館料としてこの図書館にない知識を要求する。ペンタドロンの襲撃を知りながら黙っており、
「お主らの実力と性根を見たかった」と後から白状した。
オニキスの事情を知る理解者でもある（「オニキス達者での。お主が探しているものはきっと見つかるじゃろう」）。

### ボブ／ボブ・セレス

| 項目 | 内容 |
| --- | --- |
| 立場 | 依頼人。自称「遺跡の研究職。代々そういう家系」 |
| 所持マジックアイテム | クローク・オヴ・エルヴンカインド、リング・オヴ・インヴィジビリティ、バッグ・オヴ・ホールディング |
| 特性 | 心を読ませない（エフィの看破が完全に通らない）。幽霊が大の苦手 |
| 正体 | ネザリル帝国の研究者 **カリオン・セレス** の子孫 |

紳士的な優男。エアリュオンが現れるたびに姿を消す不審な行動を取り、
第4話でペンタドロンにもう一つのネザースクロールを渡す「裏切り」を見せる。
だがその真の目的は **「彼女（エアリュオン）を助けたい」** ――
先祖カリオンが石板に遺した言葉を、宛先である竜に届けることだった。

> 「全く、じいさんのラブレターを読まないといけないとはとんだ辱めだ。あれが家宝とはね」
> 「まあ、でも世界を変える力。その一端は見れたよ。届いてよかったな。じいさん」

### エアリュオン

| 項目 | 内容 |
| --- | --- |
| 姿 | ボロボロの、青い目をした儚げな少女（幻影） |
| 正体 | **アダルト・ブルードラゴン**。片翼をもがれ、耳を潰され、雷の檻に囚われている |
| 名の意味 | 「幸せを運ぶ風」（カリオン・セレスによる） |
| 制約 | 耳が聞こえない。共通語の文字が読めない。話し言葉と**竜語**のみ通じる |

パズ地方一帯の人々の夢に現れ、「助けて」と訴えていた張本人。
ジャッジに身体を剥ぎ取られ、血をドリルの動力として搾取され続けていた。
最初の願いは「助けて」だったが、最後に紡がれた言葉は **「どうか、私を殺して」**。

「私が近づくだけで人は傷つく」――ブルードラゴンとして人々を怖がらせてきたことを罪と感じ、
自らの死を望んでいた。かつて命を救った人間の子供（＝カリオン）のことを覚えている。

### ジャッジ・アイアンハート

| 項目 | 内容 |
| --- | --- |
| 立場 | アイアンハート家当代当主。トレジャーハンター |
| 評判 | 遺跡から持ち帰った宝を領民に配る人気者だった |
| 現状 | **ネザースクロールを読み、狂気に落ちた**。採掘への欲求以外のすべてを失った |
| 戦闘形態 | 巨大なゴーレム型マジックアイテムに搭乗して操作 |

パズ地方の地震の原因を作った男。地盤を無視した超深度採掘を続け、
地盤沈下・液状化・河川の枯渇を引き起こしていた。
エアリュオンの身体でドリルを作り、その血で動かしていた。
遺言は「私は真実が…未知が知りたかった…」。

### ペンタドロン

| 項目 | 内容 |
| --- | --- |
| 出身 | メカヌス（本人曰く「本場の発音」） |
| 思想 | 「この世界は私というルールによって、支配されるのだ」 |
| 経緯 | 思想が過激すぎてメカヌスからも追い出された（司書談） |
| 第4話以降 | 敗北後に地獄へ赴き、悪魔と契約して**ウォーフォージドの肉体**を獲得 |

第1話のボスにして、シリーズを通しての宿敵（そして名脇役）。
エフィに「ペンくん」と呼ばれて激怒し、マジック・ミサイルの傷を根に持ち続ける。
「マジックミサイルは悪い文明だ」「やめてくれ」「ください」など言動が愛らしい。

一方で筋は通っており、最終話では **石板の内容を読んで方針を転換**。
「そこにいたのは優しい心をもった1知的生命体だとこの石板が教えてくれた」として、
自らエアリュオンのリインカーネイト（蘇生）を提案する。

### モドロンたち（モノドロン／デュオドロン／トリドロン／クアドロン）

ペンタドロンの部下。第1話で「急ごしらえ」と評された通り、統率が取れていない。
戦闘中にPCへクイズを出し、正解すると情報を渡して自主的に機能停止する
（詳細は [06. ルール・特殊処理](06-rules-and-mechanics.md)）。
第5話ではモノドロンが再登場し、ペンタドロンからの招待を伝える案内役を務めた。
