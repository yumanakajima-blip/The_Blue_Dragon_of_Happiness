# 08. 用語集

## 地名・組織

| 用語 | 説明 |
| --- | --- |
| **キャンドルキープ** | フォーゴトン・レルム最大の図書館にして知識の宝庫。ソード海（シー・オブ・ソーズ）に面した火山岩の断崖上に建つ要塞図書館。入館には「この図書館にない知識」を納める必要がある |
| **パズ地方** | アイアンヴェイン家が統治する地方。青き竜の逸話が伝わる。地震と川の枯渇に見舞われている |
| **ネザリル帝国** | 数千年前に栄えた最も偉大な魔導文明。天空都市を建造し、死をも克服したが、神に近づこうとして滅んだ |
| **天空遺跡** | 空に浮かぶネザリルの遺構。訪れた者をドラゴンに変える装置が各区画で稼働している |
| **メカヌス** | ペンタドロンの出身次元界。秩序と法則の世界 |
| **アイアンヴェイン家** | パズ地方を統治する豪商のドワーフ家系。非公開ながら古代遺跡を代々所有 |
| **セレス家** | ネザリル帝国の研究者カリオン・セレスの家系。石板を「家宝」として語り継ぐ。ボブの家 |
| **ドラゴンの楽園** | 天空遺跡の第3区画。ジャングルが生い茂り、多くのドラゴンが闊歩する。正体は訪問者を竜に変える装置の作動範囲 |
| **制御室** | 天空遺跡の中枢。石板が安置されており、遺跡全体のエネルギー状況を幻影で表示できる |
| **ゼンタリム** | フォーゴトン・レルムの秘密結社。PCの背景として言及された（シナリオ本編には登場しない） |

## 人物

| 用語 | 説明 |
| --- | --- |
| **エアリュオン** | 幻影の少女として現れる青き竜。名の意味は「幸せを運ぶ風」 |
| **カリオン・セレス** | ネザリル帝国の研究者。処刑直前に石板へ遺言を刻んだ。子供の頃エアリュオンに命を救われた |
| **ダーグリム・アイアンヴェイン** | アイアンヴェイン家当主。ネザースクロールで狂気に落ちた |
| **ペンタドロン** | メカヌス出身のモドロン。世界を秩序で支配しようとする。後にウォーフォージドの肉体を得る |
| **ボブ（ボブ・セレス）** | 依頼人。カリオン・セレスの子孫 |
| **オニキス** | キャンドルキープの館長を務める猫。首の文字盤と魔法で意思を伝え、竜語を解する。シナリオを通しての案内役NPC |
| **司書** | キャンドルキープの案内人。老人 |

## 事物

| 用語 | 説明 |
| --- | --- |
| **青の災い** | パズ地方に伝わる、都市を襲い文明を焼いたとされる恐ろしいブルードラゴンの呼称。実際は捏造された逸話 |
| **不幸を運ぶ風** | 青い竜の飛来とともに吹く風の呼び名。石板が明かす真実は「幸せを運ぶ風」 |
| **ネザースクロール** | 古代の強力な魔法技術が記された巻物。読む者を狂わせる「古代の罠」でもある。2枚が対になっており、重ね合わせると転移ゲートが開く |
| **石板** | 永久に劣化しないマジックアイテム。「世界を変える力」の正体 |
| **エネルギー管理クリスタル** | ドラゴンの楽園のエネルギーを管理する装置。破壊すると竜化は解けるが、遺跡そのものが落下を始める |
| **ドラゴン化** | 天空遺跡の訪問者を竜へ変える効果。知力が徐々に低下し、やがて竜語しか話せなくなる |
| **雷の檻** | ダーグリムがエアリュオンを拘束していた檻。触れるとダメージを受ける |
| **ドリル（掘削機）** | ダーグリムがエアリュオンの身体から作った採掘機。彼女の血を動力とする。パズ地方の地震の元凶 |
| **ブルードラゴンの落書き** | 『ネザリル帝国の歴史』に挟まれていた絵。塗料だけが古代のもので、紙自体がマジックアイテム。物語の発端 |
| **錬金術ゾンビ／研究員ゾンビ** | ダーグリムが配った「不死のポーション」でゾンビ化した調査隊員。倒すと爆発する |
| **モドロン** | メカヌスの秩序生物。モノ／デュオ／トリ／クアド／ペンタの序列を持つ |
| **エンバーマー** | ネザリル帝国末期、滅亡を美しく脚色し虚偽の歴史を残した者 |
| **リンカーネイト** | 転生呪文。ボブから託されたネザリル製スクロールにより、エアリュオンの復活に使用された |

## 作中文献

| 用語 | 説明 |
| --- | --- |
| **帝国衰亡記** | 遺跡の資料庫にある歴史書。「竜が国を滅ぼした」という逸話が虚言であると記す。真相への最初の手がかり |
| **天空都市建築論** | 同じく資料庫の書。天空都市が今も秘匿されて実在する可能性に触れる |
| **研究員の記録** | ダーグリム隊の調査員が遺した手記。錬金術ゾンビの正体と「みんなばくはつする」の一文を含む |
