## 1. 地下1F 探索

暗い廊下。フィルネはプロデュース・フレイムで灯りを確保（暗視を持たないため）。
以降、扉はすべてオニキスの不可視のメイジ・ハンドで開けていく。

### 資料庫

乱雑に荒らされ、誰かが暴れた形跡がある。閲覧できた資料：

- **ネザリル帝国の歴史資料**（天空都市建築論／ネザースクロールについて／古代魔法のスクロール／帝国衰亡記）
- **研究員の記録**

（→ [全文はこちら](../03-world-lore.md#5-遺跡の資料庫にあった歴史資料)）

重要な情報：

| 資料 | 判明すること |
| --- | --- |
| 帝国衰亡記 | 「**竜という災害によって国が滅びたというのは虚言**」＝青き竜の逸話は捏造 |
| ネザースクロールについて | 「その断片を読むことは祝福であると同時に**呪い**でもあった」 |
| 古代魔法のスクロール | 若返り、不死、延命、**転生**呪文などの倫理を外れた呪文が存在した |
| 研究員の記録 | 隊員が呪われ、衰弱して爆発した。ジャッジが配った「不死のポーション」が唯一の望みだった。「**みんなばくはつする**」 |

- オニキス『不死のポーションでゾンビになっちゃったにゃ』
- ヴィルフリート「地上で襲ってきたゾンビたちが、この研究員ということですか」

### 発掘品保管庫

フィルネのディテクト・マジックが反応。鍵はオニキスが解錠。
→ **ポーション・オヴ・グレーター・ヒーリング** を発見（エフィが所持）。

## 2. 実験室 ― エアリュオンの正体

扉の先にあったもの：

> そこには、**雷の檻に囚われたアダルト・ブルードラゴン**がいた。
> 見るも無惨な姿で、片翼はもがれ、様々なところに古傷がある。
> **耳を潰されている。**

幻影の少女が姿を現し、告白する。

- 「もうみんなわかっていると思う。**私は目の前にいるブルードラゴンなんだ**」
- 「そう。私は悪いドラゴン。だから**少女の姿を騙って**みんなに来てもらったの。騙してごめんなさい」
- 「あと私は耳が聞こえなくて…文字も共通語はわからない…話し言葉しか…」

以降、オニキスが全員の言葉を竜語に翻訳して伝える形で対話が進む。

### 明かされる事実

| 質問 | 回答 |
| --- | --- |
| 何をしたのか | 「**私は実験のために捕まえられたの**」「ジャッジがより深く掘削するためのドリルを作るために」 |
| 悪いことをしたのか | 「私は人々を傷つけてきたから…たくさんの人を怖がらせてきた。だから悪いドラゴンだと思う。**食べたりとかはしてないけど**…」 |
| 現状 | 「ジャッジが**私の身体を剥ぎ取ってドリルを作り、私の血でドリルを動かしている**」 |
| ジャッジはなぜ狂ったのか | 「ジャッジはとあるスクロールを読んでしまった。それは古代の罠だった。人を狂わせてしまう代物。**ネザースクロール**。彼は自身の採掘への欲求以外をすべて失った」 |

彼女の身体にはポーション・オヴ・ヒーリングの点滴が伸びていた ―― 血を絞り続けるために生かされている。

- 「私はもう普通には生きられないし、このままジャッジに利用されて、誰かに迷惑をかけたくない」
- 「**だから、私を殺してほしい**」
- 「それに今までたくさん迷惑をかけてきた。だから、生きてちゃいけないと思う」

これに対するオニキスの返答が、この回の白眉。

> オニキス『迷惑なんて気にしなくていいにゃ。人間って、迷惑かけられると喜ぶとこ、あるよ？』
> オニキス『僕が本に乗っかると、おじいちゃんは喜んだよ』
>
> エアリュオン「そうなのかな。**あの子もそうだったらいいな**….」少し微笑む

### 檻の破壊

檻は触れると1d10ダメージ、格子は人が通れない。
エアリュオン曰く「強い力をかければ壊れると思う。多分**10ターンぐらい殴れば**…」。

一行は10ターンかけて殴り続け、**檻を破壊した**。

> エアリュオン「いいの？**私は生きていいのかな？**」
> オニキス『僕が許すからおっけー！』
> エアリュオン「ありがｔ…」
>
> ジャッジ「**無論、許可しない**」

## 3. ジャッジ・アイアンハート戦

巨大なゴーレム型マジックアイテムに搭乗したジャッジが登場。

- 「研究員どもよ。ようやく帰ってきたか。また竜から材料を剥ぎ取るのだ」
- 「あの掘削機によって、全てが叶う。この遺跡の全てがわかる。掘り進めるのだ！どこまでも！」
- 「私に逆らう愚かな死人どもが。ならばその身体を火薬として少しでも採掘のための発火と化せ」

（→ [データ](../06-rules-and-mechanics.md#5-ジャッジアイアンハートボス第4話)）

### 戦闘経過

- エフィのマジック・ミサイル連打で削り、オニキスがトウル・ザ・デッドを重ねる
- フィルネはクレーンアームで捕まり投擲されるも、**ムーンビーム**の精神集中を維持
- **自己崩壊の呪い**が起動しかけ、「様子がおかしい」と警戒
- オニキスの猫パンチがクリティカル、エフィが追撃
- 最後は**ムーンビームによってジャッジは蒸発**

> ジャッジ「私は真実が…未知が知りたかった…」

## 4. ペンタドロン再登場とボブの裏切り

勝利の余韻の中、聞き覚えのある声が響く。

> ペンタドロン「と思っていたのか？邪悪なドラゴンに？平和が許されると…？それは私の秩序に反するな！」

現れたのは **ウォーフォージドらしき生命体**。その手には壺のようなマジックアイテム。
呪文とともにブルードラゴンが吸い込まれ、**エアリュオンは封印された**。

- 「そして、また会ったな。エフィよ」「この傷に見覚えはあるか？**貴様のマジックミサイルでついた傷だ**」
- 「貴様らに破れたあの日私は自身の弱い身体を憎んだ」
- 「そして、願ったのだ。**せめて大型の人型がいいなあ～。と**」
- 「そこから我は地獄に向かった」「**地獄の悪魔と契約し**、我はこのウォーフォージドの身体を手に入れたのだ」

### ネザースクロールの秘密

- ペンタドロン「我はこの**ネザースクロール**の秘密を暴きに来たからな！」
- 「ジャッジは阿呆な男よ。やつはこのスクロールの秘密に気づかなかった」
- 「このネザースクロールには**対になるものが必要**とのことをな！」
- 「**ボブ！**」

> ボブ「ええ、ここにいますよ」
> ボブ「すいません。私は遺跡のすべてを明かしたかった。そのためにはすべてを利用するまでです」
> ボブ「**これがもう一つのネザースクロールです。随分探しましたよ**」

2つのスクロールを重ね合わせると、力の本流が流れ、**転移ゲート**が出現。

- ペンタドロン「**これが真の遺跡への入口だ**」
- 「ジャッジは下を掘り続けていたが…無駄だったようだな！馬鹿な男よ！」
- 「貴様らはその消耗状態で追って来れるかな？きっと追ってくれるなよ！さらばだ！」

ペンタドロンはゲートに消えた。

## 5. ボブの弁明と託されたもの

- フィルネ「……邪魔なジャッジさんを私達に倒させるため……？」
- ヴィルフリート「今一度、ボブ殿の目的をお聞かせ願いませんか」
- ボブ「私の真の目的は一つです。私の名前は**ボブ・セレス**痛！い！」（オニキスに噛まれる）
- ボブ「**私は彼女を助けたかった！それだけです！**皆さん！」

ボブが渡したもの：

- **魔法のスクロール（リインカーネイト）** ―「呪文使いなら、誰でも使えるネザリル製の呪文スクロールです」
- **ポーション・オヴ・スーペリア・ヒーリング**

> ボブ「彼女のことはお任せします。さあ、早くやつを追ってください！」

一行はボブの髭をむしり取ったり炎で焼いたりしながら（フィルネ・エフィ）、ゲートへ向かう。

> GM「そのゲートの先にあるのは希望か絶望か！　次回！最終回！遺物の正体はいったい！」

---

## この回の要点

- エアリュオン＝アダルト・ブルードラゴンという最大の中間ネタばらし
- 「殺してほしい」という願いの理由が、身体的な状況と罪悪感の両面から提示される
- ジャッジは「未知を知りたかった」だけの被害者でもあったことが遺言で示される
- ボブの立場が「裏切り者」から「目的を隠していた協力者」へ反転を始める
