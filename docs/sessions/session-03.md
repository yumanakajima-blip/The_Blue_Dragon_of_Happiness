# 第3話 遺跡への道と研究員ゾンビ

**実施日**：2026/03/04　**発言数**：約290

---

## 1. 出発準備

各自ポーション・オヴ・ヒーリングを2本ずつ購入。
食料などはボブが手配（**バッグ・オヴ・ホールディング**所持）。遺跡までは**2週間**の道のり。

## 2. 道中 ― ボブの人物像

夕食の時間、ヴィルフリートがボブに質問する。

- ボブ「私の仕事は**研究職**です。遺跡の研究をしています」
- ボブ「**代々そういう家系**でしてね。マジックアイテムやらをいじるのが好きなのです」
- ボブ「彼の遺跡についてはある程度知っていますよ。**潜入していました**からね」

### 遺跡（ダーグリムの研究所）の見取り図

```
館内 地下1F
 ├ 資料庫
 ├ 発掘品保管庫
 ├ 研究室
 ├ 実験室
 └ 遺跡入口
```

エフィの内心：「随分親しみやすい男だが、心が全く読めなかったからねぇ、どこまでが本心なんだか」

## 3. エアリュオン、二度目の出現

シチューを囲もうとしたその時、**ボブの姿が消え**、彼女が現れた。

- エアリュオン「来てくれたんだね…優しい人たち」
- 「どうかこの人たちが怪我をしませんように…無事にここまでこれますように…」

こちらの声は届かないが、姿は見えている様子。

### 言語の壁の突破

オニキスが **サイレント・イメージ** でボブの幻影を出して見せる。

- エアリュオン「でも**あの子に似ている**気がするな…あの子も大きくなったらこんな立派になってたのかも…」

文字盤による筆談を試みるも、共通語もエルフ語も通じない。
そこでオニキスが **竜語** を試したところ――

> エアリュオン「！」「**読める！読めるよ！**」

### 判明した事実

| 質問 | 回答 |
| --- | --- |
| 幻影の人物は知り合いか | 「知り合いじゃないよ。**昔仲良かったヒューマンに似ている**だけ」 |
| それはどれくらい昔か | 「昔は昔。**大昔。季節が何千回と移り変わる前**。私がまだ小さかった頃の話」 |
| 食事はできないのか | 「食べたことがないだけ、私は遠くから見てただけ。**私が近づくとみんなが傷つく**」 |

- エアリュオン「あの子も傷つけてしまった。私は多くの人を傷つけてきた。そして今も私のせいで…」
- エアリュオン「この地は今にもひっくり返りそうになっている」
- オニキス『じゃあ。君に会えたら、僕が、見えないメイジ・ハンドでちゅーるを運んであげるにゃ！』
- エアリュオン「ありがとうね。優しい黒い子」
- エアリュオン「だから**お願い、私をどうか殺してください**。これ以上誰も傷つけないために」

ヴィルフリートの **聖邪感知** には反応なし ―― **彼女は邪悪ではない**。

彼女が消えると同時にボブが姿を現す（オニキスの幻影と合わせて「ボブが2人になった！」）。

- ボブ「困りますよ。皆さん、あの幽霊が私の顔を覚えたらどうするんですか」
- オニキス『大昔からの知り合いでしょ？』→ ボブ「私の知り合いではないですよ」
- ボブ「彼女が邪悪じゃないか…それは良かった」「**本当に**」

## 4. 遺跡入口 ― 研究員ゾンビ戦

2週間の旅を終え、遺跡の入口に到着。

- ボブ「このさきにダーグリムの研究所があり、その先に遺跡がある」
- ボブ「しかし、ここにはおそらく**奴ら**が潜んでいるだろう」
- ボブ「ああ、私が研究所から逃げ出す原因になった**命無きもの**」

地面から手が伸び、**研究員の格好をしたゾンビ**が襲いかかってくる。

> ボブ「さて、ここは任せたよ。みんな。僕は先にダーグリムの様子を見てくる」
> （そう言い残し、ボブは姿を消した）
>
> オニキス「にゃっ？」そのセリフは、残る方がいうやつでは！？

### 戦闘

**錬金術ゾンビ**（→ [データ](../06-rules-and-mechanics.md#4-錬金残留反応研究員ゾンビ第3話)）

- 通常のゾンビではなく、**HPが0になると錬金残留反応でランダム爆発**する
- ヴィルフリートが粘着液で拘束されるなどの被害
- ヴィルフリートの「聖なる光」による全体攻撃（各4ダメージ）、
  フィルネの星座形態・フェアリーファイアー・ガイディングボルト、
  エフィのシャター・マジックミサイル、オニキスの猫爪＋急所攻撃で殲滅

戦闘後、オニキスが **モールド・アース** で遺体を埋葬。

- オニキス『う〇ちみたいな臭いだから同じなのにゃ！』（後ろ足で土をかける）
- ヴィルフリート「オニキス殿のおかげで埋葬時間を短縮できましたね。ボブ殿を追いかけましょう」

館内に入ると案内図があり、地下1Fの構成が確認できた。

---

## この回の要点

- 「**竜語なら通じる**」という突破口 ―― オニキスが唯一の通訳になる構図が確立
- エアリュオンとカリオン（＝ボブの祖先）の関係が示唆される
- ボブが「知り合いではない」と否定する（＝嘘ではないが、真実を隠している）
- ダーグリム隊の惨状が「爆発するゾンビ」として実体化する
