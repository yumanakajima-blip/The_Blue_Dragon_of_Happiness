## 2. ブルードラゴンの落書き

オニキスが、かつての飼い主（おじいさん）が大切にしていた本を持ってくる。
その本には一枚の絵が挟まれていた ―― 子供が描いたようなタッチのブルードラゴン。

- オニキス『これは僕が描いたんじゃないよ』
- 司書「その落書きは、【ネザリル帝国の歴史】の本が寄贈されていた際に挟まれていたものでの」

さらにオニキスは、おじいさんから聞いていた **パズ地方に伝わる青き竜の逸話**
（→ [全文](../03-world-lore.md#3-パズ地方に伝わる青き竜の逸話)）を石板で説明し、
精巧なブルードラゴンの絵が載った図鑑を持ってくる。

### 落書きの謎（看破／捜査判定）

図鑑の精巧な絵と子供の落書きを見比べる判定。オニキスのみ有利。

| 判明した事実 |
| --- |
| 用紙自体は落書きの方が新しく感じるが、**使用されている塗料は遥か古代のもの** |
| 司書曰く、本は **600年前に匿名のヒューマンから**「大切にしてくれ」との言伝つきで寄贈された |
| フィルネのディテクト・マジック（儀式）により、**この紙自体がマジックアイテム**と判明（系統・用途は不明） |

- 司書「ホッホッホッ、どうやらボブのやつは随分優秀な冒険者を見つけられたようじゃの」
- 司書「パズ地方に向かうんじゃ！探せ！この世のすべてがそこにおかれているじゃろう！」
- 司書（心の声）「オニキス達者での。お主が探しているものはきっと見つかるじゃろう」

## 3. パズ地方 ― 奇妙な夢

2週間の旅を経てパズ地方へ。パズ地方の近くまで来た晩から、
**全員が同じ夢**を見るようになっていた。

> 綺麗な青い目をした少女が何かを必死に訴えている夢だ。
> 彼女の姿はよく見るとボロボロで、虐待を受けている少女のような印象だ。

酒場で聞き込みを行うと、**住民の多くが2ヶ月前から同じ夢を見ている**ことが判明。
ヴィルフリートによる似顔絵は評判が良く、フィルネの絵は前衛芸術（ピーマンの精霊）と化した。

### 噂話 ― 地殻変動

> - 最近、この地域では地震が頻発している。発生時刻は不規則で、昼夜を問わず揺れが確認されている。
> - 地震の影響により、川の水位が低下し、一部では干上がり始めている。
>   このため、農作物への被害や生活用水の不足が発生している。
> - **ダーグリム・アイアンヴェインが遺跡に向かってから約1年が経過している。**
>   出発時には「短期の調査で戻る」とされていたが、現在まで一切の連絡がない。
> - 一方で、地元住民の間では「今回も何か価値ある宝を持ち帰ってくるのではないか」との期待の声も残っている。

- フィルネ「地震が多いというのも気になります。星を詠む限り、当分地震が起こる兆候はないはずなのですが」

## 4. 依頼人ボブとの合流

依頼人 **ボブ** が登場。紳士的な優男。

- オニキスとフィルネが、ボブが高価なマジックアイテムを所持していることを看破
  → **クローク・オヴ・エルヴンカインド** と **リング・オヴ・インヴィジビリティ**
- オニキスが不可視のメイジ・ハンドで**指輪を盗む**（後に返却）

### ボブの説明

- 「この街は今危機に瀕している。いや、この地方というのが適切か」
- 「その地震は自然でも神の意志でもない。**人為的なもの**で引き起こされている」
- 「その人物は他でもない。**ダーグリム・アイアンヴェイン**。やつが行っている」
- 「やつは**地盤をすべてひっくり返しながら、この大地の奥深くまで掘り進めている**。地盤への影響をかんがみずに」
- 「その結果地盤は沈下し、液状化現象と地震の発生が起きているのだ」
- 「やつが調査している遺跡では…とある遺物が関連していることがわかった」
- 「それは**世界を変えるほどの力**を持つ恐ろしい遺物だと聞く」
- 「……そうだな…**神に匹敵する力**を持つやもしれぬとだけ伝えておこう」

報酬として **1人300GP＋前金100GP** が提示され、一行は依頼を受諾する。

## 5. エアリュオン、実体化する

契約の直後、酒場に少女の声が響く。「**助けて**」と。

酒場の中央に、夢の少女が浮かんでいた。

- 「私は**エアリュオン**。どうか私を助けて」
- 「わたしのせいで。この街は今危機に瀕している…私の声が聞こえる人。もしいれば」
- 「あいつは、ダーグリム・アイアンヴェインは気が狂っている」
- 「やつの採掘機はやがてこの地球の奥深く。**マントルにまで到達するでしょう**」
- 「やつは気が狂ってしまった。遺跡の幻影をおい、ただ破滅への道を掘り進めている」
- 「どうか…やつを止めるために」

そして、消えかかる唇から最後の言葉が紡がれた。

> **「どうか、私を殺して」**

### ボブの不審な行動

少女が現れた瞬間、ボブは**クローク・オヴ・エルヴンカインドで姿を消し、樽の中に隠れていた**。
本人は「幽霊の類がとても苦手でね…」と釈明。

**エフィの看破の結果**：
> エフィは彼の心が全く読めないことに気づいた！
> 彼は異様なまでに自身の心を隠すことに長けているようだ！

エフィは出発前に、この事実を仲間に共有した。
