# 第1話 キャンドルキープの珍客

**実施日**：2026/01/28　**発言数**：約394　**獲得XP**：1,150

---

## 1. 導入 ― 酒場の回想

> 賑やかな酒場。あなた達は仲間と一緒に酒精が染み込んだ机を囲んでいるところだ。
> 話題にしているのは、昨日の奇妙な遭遇。キャンドルキープの図書館での出来事だった。

石畳に「今日の朝ご飯を尋ねる文言」が刻まれており、
老人（司書）が杖を振って【メンディング】で消してしまう――という場面から回想が始まる。
落書きの主は、この図書館の**館長**であるという猫、オニキスだった。

- フィルネ「ぅぇぇえええ！！ ネコチャンが館長ォ！！？？」
- 司書「そうじゃ、この子はうちに住み着く名物猫での」

## 2. 入館プレゼン

司書から入館条件が提示される。「この図書館にはない知識・書物を入館料として納めること」。

| PC | 提示物 | 結果 |
| --- | --- | --- |
| オニキス | 手本として実演 | 失敗。「まるでゴブリンの落書きのようだな」と酷評され伏せ状態に |
| フィルネ | 『何故こぐま座は星2つでこぐまなのか？』 | **成功**（有利）。インスピレーション獲得 |
| ヴィルフリート | 日記『守護天使ラキュエルとの愉快適悦な日々』 | 成功。インスピレーション獲得 |
| エフィ | 『カガの日記』 | 成功。「後世に残すべき恥じゃ！教訓にしよう…」 |

フィルネがシルヴァナスとエルダスの親子関係から語り始めて止まらなくなり、
司書に**サイレンス**をかけられるという一幕も。

- オニキス（石板）『本じゃなくて、あの子を図書館に収めてしまった方が早いかもね』

司書は入館を認め、「今は珍客がおっての！騒がしいかもしれん！」と言い残す。

## 3. ペンタドロン襲撃戦

館内では **ペンタドロン** が四体のモドロンを従えて暴れていた。

- ペンタドロン「このキャンドルキープはこのペンタドロンが占拠した！すべての叡智を我が手元に収めるのだ！」
- ペンタドロン「ここには世界を征服できる異物が眠る遺跡のありかがあるらしい！みな探し出すのだ！」
- ペンタドロン「我名はペンタドロン！**メカニス**より、この世界を秩序と法則によって支配するためにやってきた！」
  → 「ちなみに**メカヌス**だ！噛んでないぞ！本場の発音ってやつだ！」

エフィが「ペンくん」と呼んだことで因縁が発生する。

### クイズ戦闘

GMから特殊戦闘ルールが提示され、各PCのターンにモドロンが問いを出す形式となった
（→ [ルール詳細](../06-rules-and-mechanics.md#2-クイズ戦闘モドロン戦第1話)）。

4体すべてのモドロンが正解によって機能停止し、それぞれ情報を残していった。
モノドロンはエフィに「君の弟さん無事ならいいね…」と意味深な一言を残す。

### 戦闘経過

- ペンタドロンの **麻痺ガス**（DC11【耐久力】セーヴ／1分間麻痺）でフィルネとオニキスが麻痺
- フィルネはインスピレーションを使って麻痺を脱出「こぐま座が助けてくれた……気がする！」
- エフィのマジック・ミサイル連打が刺さり、ペンタドロンは半減
  → 「マジックミサイルは悪い文明だ」「やめてくれ」「ください」
- エフィ「人に頼むときはそれ相応の【頼み方】があるよねぇ…？」
  → ペンタドロン「ああ！頼む！許してくれ！心を入れ替えよう！」**頭を4つ下げる**（1つ足りない）
- 交渉と見せかけて攻撃を継続。ヴィルフリートのロングソードでペンタドロンは倒れる

## 4. 戦闘後

ペンタドロンはポータルを開いて別次元界へ逃走。「覚えてろよ～！！」

- 司書「ペンタドロン…愚かな男よ。やつは思想が過激なばかりにメカヌスすら追い出されたのだ」
- 司書「やつも入館料は払ったしの…それにお主らの実力と性根を見たかった…」

司書からポーション・オヴ・グレーター・ヒーリングが贈られ、
一行は本題である遺跡の調査へと移るのだった。
