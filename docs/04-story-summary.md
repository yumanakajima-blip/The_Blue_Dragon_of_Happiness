# 04. あらすじ・時系列

## 全体のあらすじ

**きっかけ。** 冒険者たちはパトロン「ボブ」から空中古代遺跡の調査依頼を受け、
情報を求めて大図書館キャンドルキープを訪れる。入館料として各自の知識を納め、
そこで図書館を占拠していたメカヌスの秩序狂・ペンタドロンを撃退する。
モドロンたちからは、ネザリル帝国とアイアンハート家に関する情報が得られた。

**手がかり。** 『ネザリル帝国の歴史』を唯一借りていたのはジャッジ・アイアンハート。
そして本には、館長猫オニキスの亡き飼い主が大切にしていた
「ブルードラゴンの落書き」が挟まれていた。用紙は新しいのに塗料は古代のもの、
しかも紙自体がマジックアイテム。一行はアイアンハート家の地元、パズ地方へ向かう。

**依頼と幽霊。** パズ地方では地震が頻発し、川が枯れ始めていた。
そして住民の多くが「ボロボロの少女」の夢を見ていた。
依頼人ボブと合流した一行は、地震の原因がジャッジの常軌を逸した超深度採掘であることを知る。
その最中、夢の少女が実体化して現れ、こう告げる――「助けて」、そして「どうか、私を殺して」。

**遺跡へ。** 2週間の旅路で少女は再び現れ、彼女には**竜語しか通じない**ことが判明する。
遺跡入口では爆発するアンデッド「研究員ゾンビ」が襲いかかってきた。

**真実。** 研究所の資料庫で、ジャッジ隊が「ネザースクロール」の解析によって
呪われ全滅していたことが分かる。そして実験室で一行が見たのは、
片翼をもがれ耳を潰され、雷の檻に繋がれた **アダルト・ブルードラゴン** ――
夢の少女エアリュオンの正体だった。彼女の身体はドリルの材料に、
血はその動力に使われていた。一行は檻を破壊するが、そこにジャッジが現れ、戦闘となる。

**裏切りと転移。** ジャッジ撃破直後、ウォーフォージドの肉体を得たペンタドロンが再登場。
エアリュオンを壺状のマジックアイテムに封印し、さらにボブが**もう一つのネザースクロール**を
ペンタドロンへ手渡す。2つのスクロールを重ね合わせると転移ゲートが開いた。
「真の遺跡」への入口である。ボブはリンカーネイトのスクロールを託し、一行を送り出す。

**天空遺跡。** ゲートの先はドラゴンの楽園だった――が、そこは
訪れた者を**ドラゴンに変えてしまう**エリア。フィルネを除く全員が竜と化し知性を失う。
フィルネは元凶であるエネルギー管理クリスタルを発見し、竜化した仲間のブレス一斉掃射で破壊。
変身は解けたが、同時に長年ドラゴンでいた者たちが元の姿に戻り、灰と化して消えていった。

**世界を変える力。** ペンタドロンに招かれた制御室で、一行は「世界を変える力」の正体を知る。
それは **永久に劣化しない石板** と、そこに刻まれたネザリル帝国の研究者
**カリオン・セレス** の遺言だった。処刑を待つ彼が、かつて自分の命を救った青い竜へ宛てた手紙。
「エアリュオン。幸せを運ぶ風よ。君が多くの友人に囲まれて幸せになることを願って」。

ペンタドロンは方針を転換し、エアリュオンのリンカーネイトを提案する。
だがその瞬間、第3区画のエネルギー装置破壊（＝一行がやったこと）により
遺跡が落下を始めた。石板は大きすぎて持ち出せず、オニキスがサイレント・イメージで模写。
一行はフェザーフォールで脱出し、天空遺跡は海へ沈んでいった。

**エピローグ。** 数日後の酒場。生まれ変わったエアリュオンは骨付き肉に噛りつき、
「このお肉とっても美味しいわね！」と笑っていた。
一人500GPの報酬を残して逃げようとするボブ。その正体はカリオン・セレスの子孫であり、
彼の目的は最初から**先祖のラブレターを宛先に届けること**だけだった。

> 「まあ、でも世界を変える力。その一端は見れたよ。届いてよかったな。じいさん」

エアリュオンは、石板の模写を胸に抱えて大切にしたのだった。

## 伏線と回収

| 伏線（提示） | 回収 |
| --- | --- |
| 導入「遺跡には様々な竜たちが闊歩している」 | 第5話：ドラゴンの楽園（＝訪問者がドラゴン化する区画） |
| 導入「世界を変える技術がある」 | 第5話：永久に劣化しない石板 |
| 落書きの塗料だけが古代のもの／紙自体がマジックアイテム | **明示的な回収はなし**。石板に刻まれていた「一枚の絵」との対応が示唆されるにとどまる（GM裁量の余地あり） |
| 600年前の匿名のヒューマンによる寄贈 | セレス家による、竜へ手がかりを託す長い試み |
| エアリュオンが「あの子に似ている」とボブを見て言う | ボブ＝カリオン・セレスの子孫 |
| ボブの心が一切読めない | 目的を隠していたため。真意は「彼女を助けたい」 |
| 青き竜の逸話＝「不幸を運ぶ風」 | 石板：「エアリュオン。幸せを運ぶ風よ」＝逸話は捏造だった |
| 『帝国衰亡記』「竜が滅ぼしたというのは虚言」 | 上記と同じ真相の裏付け |
| 研究員の記録「みんなばくはつする」 | 研究員ゾンビの錬金残留反応（爆発） |
| ジャッジが借りていた本＝『ネザリル帝国の歴史』 | ネザースクロールに至り、狂気に落ちた経緯 |
| エフィがペンタドロンに与えたマジック・ミサイルの傷 | 第4話：ウォーフォージドの身体にも同じ傷を刻んで再登場 |
| 一行が第3区画のクリスタルを破壊した | 第5話終盤：遺跡のエネルギー不足→落下、脱出劇の原因 |
