# 幸せの青い竜 — The Blue Dragon of Happiness

D&D 5e シナリオ **「幸せの青い竜（The Blue Dragon of Happiness）」** の
**復元シナリオ** と **実プレイ記録アーカイブ**。

- **レベル**：4
- **プレイ時間**：約9時間（夜3日程度）
- **実セッション**：全5回（2026/01/28 〜 2026/04/30）
- **ジャンル**：探索・戦闘
- **舞台**：空に浮かぶ古代遺跡都市（フォーゴトン・レルム／ネザリル帝国の遺構）

> プレイヤーたちは、それぞれのロマンを胸に、伝説の古代遺跡へと足を踏み入れる。
> 財宝を見つけるため。知識を得るため。少女の願いに応えるため。――あるいは。
> 探索の先にあるのは、ただの財宝や知識ではない。
> 誰かの願いが、今もなお風に乗って漂っている――

## この資料について

原典はセッション中のチャットログ（発言 1,801 件）です。
`docs/` はそのログを読み解いて再構成した記録・設定資料、
`scenario/` はそれを土台に復元したGM用シナリオ本体です。

ダイスの出目やHP増減といった処理ログは原則省略し、
物語・設定・ルール裁定に関わる情報を中心にまとめています。
作中の台詞・文献テキストはすべて原ログからの引用です。
